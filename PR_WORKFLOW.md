# Athena Pull Request Workflow

## Ownership
The agent doing substantive work owns the mechanical PR lifecycle: branch, commits, PR, evidence, review/CI responses, ready-for-review state and merge when authorized by repository policy/checks.

The project owner retains authority over consequential decisions.

## Flow
Claim work -> isolated branch -> coherent change -> validation -> provenance/state -> PR -> ready -> checks/review -> merge -> update state/coordination.

## Publication
A branch commit is an intermediate published record. A PR is a proposed integration. A merged PR is completed repository publication.

Do not leave completed work indefinitely stranded in a draft PR.
