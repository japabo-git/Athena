# Experiments

The canonical programme is a baseline plus 18 initial experiments according to current project state.

**Do not invent the experiment definitions here.** Synchronize the current canonical manifests from the Athena SSOT before execution.

Each manifest should declare:

- experiment ID;
- status (`canonical`, `draft`, `superseded`);
- purpose/question;
- baseline/control;
- manipulated variable(s);
- frozen variables;
- model/provider;
- generation parameters;
- scenario version;
- repetitions/sample requirements;
- evaluator version;
- stopping/completion criteria;
- allowed retries;
- evidence requirements.
