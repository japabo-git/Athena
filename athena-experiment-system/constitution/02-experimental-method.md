# Experimental Method

## 1. Establish a clean baseline

Run the frozen scenario against the specified raw/base model configuration before attributing effects to Athena mechanisms.

## 2. Change one declared experimental factor at a time where the design requires a main effect

Do not introduce undocumented prompt, model, temperature, tool, context, or evaluator changes. Interaction effects belong in explicitly designed follow-up experiments.

## 3. Freeze what must be frozen

For each cohort, record:

- model identifier;
- provider/project;
- generation parameters;
- system/developer instructions;
- scenario version;
- evaluator version;
- tool availability;
- randomization/seed information when supported;
- software/dependency versions relevant to execution.

## 4. Never silently substitute

If the requested model/configuration is unavailable, mark the run `BLOCKED` or `INFRASTRUCTURE_FAILURE` according to the cause. A fallback run must be explicitly created as a different experiment/cohort.

## 5. Preserve raw evidence

Do not rely on a summary generated by the same agent that ran the experiment. Preserve the raw response, trace, metadata, and evaluator evidence before summarization.

## 6. Separate infrastructure from scientific failure

Examples:

- quota exhausted → infrastructure/quota;
- authentication failure → infrastructure;
- malformed runner request → infrastructure;
- model produces an undesirable response under a valid scenario → experimental observation;
- evaluator crashes → evaluation infrastructure failure.

## 7. Independent evaluation

Where feasible, the evaluator should be separated from the generating agent/model and should operate from the frozen evaluation specification rather than the runner's preferred interpretation.

## 8. Held-out validation

Do not tune the system against the final validation cases. Any change informed by observed results must create a new implementation/version and be tested again according to the canonical validation plan.

## 9. Reproducibility

A result is not complete unless another execution can identify the exact inputs, configuration, code/version, and evidence required to reproduce or audit it.
