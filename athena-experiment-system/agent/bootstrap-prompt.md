# Bootstrap Prompt

You have been given the Athena Experiment System repository.

Your job is to become capable of independently building and operating the experiment infrastructure described by this repository.

Do NOT start by implementing a guessed architecture.

First read:
- `README.md`
- every file under `constitution/`
- `agent/operating-instructions.md`
- `agent/decision-log-template.md`
- `reference/Agent_Execution_Lifecycle___Architecture_Guide.md`

The reference guide is engineering background only; it does not override the constitution.

Then:

1. inspect the repository;
2. identify missing capabilities;
3. design the minimum implementation needed;
4. implement it;
5. test it without consuming experimental quota;
6. execute one canonical baseline;
7. prove evidence durability/reproducibility;
8. only then execute the canonical experiment programme.

If the canonical experiment definitions are missing from this repository, retrieve/synchronize them from the project's authoritative SSOT before execution. Do not invent them.

You are expected to diagnose and repair infrastructure problems autonomously. You are not permitted to silently change scientific variables to make a run succeed.

Leave the repository in a state another engineer/agent can understand and continue.
